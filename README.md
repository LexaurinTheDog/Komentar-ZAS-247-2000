# Komentář k zákonu č. 247/2000 Sb., o získávání a zdokonalování odborné způsobilosti k řízení motorových vozidel a o změnách některých zákonů

Otevřený komentář k zákonu o získávání a zdokonalování odborné způsobilosti k řízení motorových vozidel (zákon o autoškolách) — § po §: doslovné znění, výklad, kazuistika, protiargumenty a praktický závěr; registrace a provozování autoškol, výuka a výcvik, učitelé, zkoušky žadatelů o řidičské oprávnění, profesní způsobilost řidičů, školení řidičů, státní dozor, přestupky a přílohy.

Konsolidované znění: dokument e-Sbírky `SB-2000-00247_2025-07-01`.
